## Projekt

- **[ansible-labbar](https://github.com/LoveS-prog/ansible-labbar)**: Två Ubuntu servrar som sätts upp från en kontrollnod med ett kommando. Nginx framför Gunicorn och Flask på den ena, MariaDB på den andra, med roller, Ansible Vault och Jinja2 mallar.
- **[pipeline-projekt](https://github.com/LoveS-prog/pipeline-projekt)**: Flask app där all kod går via pull requests till en skyddad main. Pipelinen kör lint, tester och ett integrationstest och pushar sedan en image till GHCR, taggad med commit SHA.
- **[kubernetes-pipeline](https://github.com/LoveS-prog/kubernetes-pipeline)**: En push till main testar appen, bygger en image och deployar den i Kubernetes med Helm. Prometheus och Grafana för övervakning.
